# KWCAG 2.2 점검 기록

- **점검일:** 2026-11-08 (0.5.0), 2026-11-16 재점검(0.7.0·1.0.0, 아래 '0.7.0에서 고친 것'·'1.0.0에서 고친 것')
- **대상:** 공개 사이트 한국어·영어(첫 화면, 아카이브, 유물 화면, 초안 미리 보기, 404), 관리 화면(로그인, 대시보드, 유물 목록, 유물 편집, 주석 편집기)
- **환경:** 프로덕션 빌드, Chromium, 1280×800과 360×780
- **항목 번호:** 비공식 정리본 <https://a11ykr.github.io/kwcag22/> 기준. 인용·인증에는 공식 문서(KS X OT0003)로 확인해야 합니다.

## 어떻게 확인했는가

| 방법 | 범위 |
|---|---|
| axe (두 앱의 스토리 테스트, E2E) | 색 대비, 이름 없는 컨트롤, ARIA 오용, 보이는 글자와 이름 불일치 등 자동 검출 항목 |
| Playwright 측정 스크립트 | Tab 순회(초점 표시, 화면 안 여부, 다른 요소에 가림), 컨트롤 크기, 제목·언어, 중복 id, 콘텐츠 모델(`button` 안 대화형 요소, `ul` 자식), 레이블과 네임, 새 창 안내, 가로 넘침 |
| 코드 읽기 | 키 처리, 시간 제한, 움직임, 포인터 동작, 인증 흐름 |

**하지 않은 것:** 실제 화면 낭독기(센스리더, NVDA, VoiceOver, TalkBack)로 들어 보지 않았습니다. 자동화 환경에서는 낭독 결과를 확인할 수 없습니다. 아래의 '통과'는 위 방법으로 확인한 범위의 판단이며 인증이 아닙니다.

## 항목별 결과

표기: 통과, 부분(한계 있음), 해당 없음.

| 5.3.2 선형구조 | 통과 | DOM 순서가 읽는 순서와 같음. 뷰어의 주석 번호는 목록 순서와 같음 |

### 운용

| 항목 | 결과 | 근거 |
|---|---|---|
| 6.1.1 키보드 | 통과 | 모든 페이지를 Tab으로 순회. 딥줌은 화살표·+/−·0. 주석 영역은 끌기 없이 '보이는 영역으로 추가'와 숫자 입력으로 만듦. 딥줌 전체 화면에서도 도구 막대·이동 버튼을 그대로 씀(0.7.0) |
| 6.1.2 초점 이동·표시 | 통과 | 순회한 컨트롤 모두 초점 표시가 있고 화면 안에 들어옴. 점검 중 하단 고정 메뉴·저장 막대에 초점이 가리는 문제를 찾아 `scroll-padding-bottom`으로 고침. 주석 편집기의 SVG 초점 표시도 추가. 화면보다 긴 입력칸은 일부가 저장 막대 아래에 있을 수 있으나 전부 가리지는 않음. 입장 화면(모달)이 열린 동안 초점이 가려진 메뉴·바로가기 링크로 빠지던 것을 고침(0.7.0, E2E) |
| 6.1.3 조작 가능 | 통과 | 공개 사이트의 컨트롤은 44px 안팎. 24px 미만은 글 속 링크 높이(20~23px, 너비 61px 이상)뿐이고 주석 목록 버튼은 24px로 키움. 사이드바 경계(폭 16px)는 같은 기능의 버튼이 따로 있음 |
| 6.1.4 문자 단축키 | 통과 | 한 글자 키는 뷰어에 초점이 있을 때만 동작. 주석 편집기의 실행 취소·다시 실행은 Ctrl/⌘ 조합 키이고, 입력 칸 안에서는 브라우저의 글자 실행 취소를 그대로 둠(1.0.0) |
| 6.2.1 응답시간 조절 | 통과 | 공개 사이트에 시간 제한 없음. 관리 화면 세션은 12시간이며, 시연용 |
| 6.2.2 정지 | 통과 | 히어로 전환, 스크롤 연출, 안내 투어를 메뉴의 움직임 버튼과 운영체제 설정으로 멈춤 |
| 6.3.1 깜빡임 | 통과 | 초당 3회 이상 깜빡이는 효과 없음(히어로는 1.4초 교차 전환) |
| 6.4.1 반복 영역 건너뛰기 | 통과 | 첫 Tab에서 본문 바로가기 |
| 6.4.2 제목 | 통과 | 페이지마다 제목이 다름. 점검 중 404 화면 제목이 일반 제목이던 것을 고침(운영의 정적 404에서도 맞도록 2026-11-10 보완) |
| 6.4.3 링크 텍스트 | 통과 | 카드는 유물 이름, 새 창 링크는 '(새 창)' 표기(자동 확인) |
| 6.4.4 고정 참조 위치 | 해당 없음 | 쪽 번호가 있는 출판물이 아님 |
| 6.5.1 단일 포인터 | 통과 | 확대·축소, 상하좌우 이동, 주석 이동이 모두 버튼 한 번으로 됨(2026-11-11 이동 버튼 추가, 모바일 E2E로 확인). 넓은 화면은 미니맵으로도 이동 |
| 6.5.2 포인터 취소 | 통과 | 동작은 `click`(올릴 때) 기준. 사이드바 끌기는 놓을 때 확정하고 취소 시 되돌림 |
| 6.5.3 레이블과 네임 | 통과 | `aria-label`이 보이는 글자를 포함함(자동 확인). 점검 중 언어 전환 링크 "KO/EN"을 언어 이름으로 바꿔 고침. 관리 화면의 쪽 번호 링크와 계정 메뉴 버튼도 고침(1.0.0) |
| 6.5.4 동작기반 작동 | 해당 없음 | 기기 움직임을 쓰지 않음 |

### 이해

| 항목 | 결과 | 근거 |
|---|---|---|
| 7.1.1 기본 언어 | 통과 | `<html lang>`이 언어판마다 다름. 영어판에 남은 한국어 내용과 언어 링크에 `lang` 표시 |
| 7.2.1 사용자 요구 실행 | 통과 | 초점만으로 화면이 바뀌지 않음. 검색 결과는 입력 초점을 유지하고 개수를 알림. 새 창으로 여는 미리 보기 링크는 "(새 창)"을 이름에 넣음 |
| 7.2.2 찾기 쉬운 도움 | 통과 | 질문 섹션과 꼬리말이 언제나 같은 자리에 있음 |
| 7.3.1 오류 정정 | 통과 | 관리 화면 폼은 필드별 오류 문구를 칸에 잇고(`aria-describedby`·`aria-errormessage`), 실패하면 첫 오류 칸으로 초점을 옮김(0.7.0). 저장 실패(연결 끊김 포함)는 입력을 지우지 않음. 다른 곳에서 먼저 저장했으면 덮어쓰지 않고 원인과 할 일을 알림, 주석 편집기는 실행 취소, 저장하지 않고 떠나면 확인(1.0.0) |
| 7.3.2 레이블 | 통과 | 입력칸마다 `label` 또는 이름(axe). 칸 설명도 칸에 이음(0.7.0) |
| 7.3.3 접근 가능한 인증 | 통과 | 이메일·비밀번호, 붙여넣기 허용, `autocomplete` 지정, 인지 시험 없음. 게스트 입장 제공 |
| 7.3.4 반복 입력 | 해당 없음 | 여러 단계에서 같은 값을 다시 받는 흐름 없음 |

| 8.2.1 웹 애플리케이션 접근성 | 부분 | axe 위반 없음(관리 화면은 0.7.0부터 로그인·대시보드·목록·새 유물·주석 편집기까지 E2E로 검사), 커스텀 컨트롤의 키보드 동작 구현. 상태 메시지는 처음부터 있는 영역에서 알림. **화면 낭독기로 실제 낭독을 확인하지 못함** |

## 이번 점검에서 고친 것

- 초점이 하단 고정 메뉴와 저장 막대에 가리던 문제(6.1.2)
- 주석 편집기 SVG의 초점 표시(6.1.2)
- 404 화면의 제목(6.4.2)
- 언어 전환 링크의 보이는 글자와 이름 불일치(6.5.3)
- 주석 목록 버튼 높이(6.1.3)
- 좁은 터치 화면에서 끌기 없이 사진을 옮기는 이동 버튼(6.5.1, 0.5.1)

## 0.7.0에서 고친 것 (2026-11-16)

- 입장 화면이 열린 동안 본문 바로가기 링크와 아래쪽 메뉴가 막히지 않아 초점이 가려진 곳으로 빠지던 것(6.1.2, 모달): 입장 화면 밖을 모두 `inert`로 막음
- 딥줌 전체 화면에서 도구 막대·이동 버튼이 사라지던 것(6.1.1): 뷰어 틀 전체를 전체 화면으로. 요소 전체 화면을 지원하지 않는 iPhone에서는 빠져나올 수 없던 버튼을 숨김
- 관리 화면 폼 오류가 칸과 이어지지 않고 칸마다 `role="alert"`가 생기던 것(7.3.1·7.3.2): 오류·설명을 칸에 잇고, 알림은 폼 바깥의 영역 하나로, 첫 오류 칸으로 초점 이동
- 주석 편집기의 뷰어 틀이 초점을 받는 캔버스를 품은 채 `role="img"`이던 것(8.2.1): 설명 글로 바꿈
- 상태 메시지: 아카이브 결과 수의 중복 `aria-live`, 오류가 날 때 새로 생기던 알림을 처음부터 있는 영역으로, 안내 투어가 번호와 설명을 두 번 읽던 것
- 연표의 가로 스크롤 영역이 역할 없이 이름(`aria-labelledby`)을 가지던 것: `role="region"`
- 아카이브 셀렉트의 화살표를 직접 그려 오른쪽 간격을 왼쪽 글자 간격과 같게 함

## 1.0.0에서 고친 것 (2026-11-16)

관리 화면에도 스토리 테스트(axe)를 붙이자 E2E가 지나치던 것이 나왔습니다.

- 유물 목록 쪽 번호 링크의 이름 "1쪽"이 보이는 글자 "1"을 낱말로 품지 않던 것(6.5.3, `label-content-name-mismatch`): "1 쪽"으로 띄움
- 계정 메뉴 버튼의 `aria-label`("계정 메뉴")이 보이는 이름과 달랐던 것(6.5.3): 보이는 이름 + 화면 낭독기용 "계정 메뉴"로 이름을 만들고 아바타는 꾸밈으로
- 이미지 카드의 "이미지 없음" 글자 대비 4.34:1(5.4.3): 4.5:1 이상으로
- 새 기능도 같은 기준으로 만듦: 실행 취소·다시 실행 버튼(보이는 아이콘 + 이름, `aria-keyshortcuts`), 편집 충돌 알림(유물 폼은 처음부터 있는 `role="alert"` 영역, 주석 편집기는 처음부터 있는 알림 목록), 초안 미리 보기 안내(본문 맨 앞, 끝내기 버튼은 폼 제출)
